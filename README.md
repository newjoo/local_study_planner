\# Local Study Planner

책의 목차, 학습 기간을 입력하면 남은 기간을 기준으로 하루 학습 분량을 자동으로 나누어 주는 로컬 학습 계획 프로그램입니다.

핵심 기능부터 단계적으로 구현할 예정입니다.

<hr>

\# 프로젝트 목표

이 프로젝트의 핵심 목표는 아래와 같습니다.

* 책의 목차를 문자열로 입력받기
* 목차를 챕터 또는 학습 단위로 나누기
* 목표 완료일을 입력받기
* 남은 학습 가능 일수를 계산하기
* 전체 학습량을 날짜별로 자동 분배하기
* 오늘 해야 할 학습 분량을 확인할 수 있게 만들기

<hr>

\# 개발 계획

\## 1단계 - 프로젝트 구조 생성

* \[ ] Python 프로젝트 구조 생성
* \[ ] `main.py` 실행 확인
* \[ ] 목차 입력을 문자열로 받을 수 있도록 입력 처리

\## 2단계 - 목차 파싱 기능

입력된 목차 문자열을 분석해 학습 단위로 나누는 기능 구현

목차 형식이 개체마다 다르다는 점을 감안, 다수의 형식을 처리할 수 있도록 확장

* \[ ] 목차 문자열 줄 단위로 분리
* \[ ] 빈 줄 및 불필요한 공백 제거
* \[ ] 주요 목차와 세부 목차 구분
* \[ ] 목차 형식의 다양성 지원
* \[ ] 사용자가 잘못 분리된 결과를 수정할 수 있는 방식 검토

\## 3단계 - 날짜 계산 기능

시작일과 완료일을 기준으로 실제 학습 가능한 날짜 계산

* \[ ] 시작일 입력
* \[ ] 완료일 입력
* \[ ] 남은 일수 계산
* \[ ] 날짜별 목록 생성
* \[ ] 잘못된 날짜 입력 처리

\## 4단계 - 하루 학습량 계산

전체 학습량과 남은 날짜를 기준으로 하루 학습량 계산

학습 단위를 최대한 균등하게 날짜별로 분배하는 것을 목표

* \[ ] 전체 학습 단위 개수 계산
* \[ ] 하루 평균 학습량 계산
* \[ ] 나머지 학습량 균등 분배
* \[ ] 날짜별 학습 계획 생성
* \[ ] 목표일 변경 시 자동 재계산

\## 5단계 - 오늘의 학습 계획 출력

전체 계획 중 오늘 해야 할 학습 내용을 확인

* \[ ] 전체 학습 계획 생성 및 출력
* \[ ] 오늘 날짜 확인 및 출력
* \[ ] 오늘 학습할 항목 출력
* \[ ] 완료 여부 표시

\## 6단계 - 학습 진행 상태 저장

프로그램 종료 후 재실행 시 기존 데이터 상태가 유지되어야 함

* \[ ] 학습 계획 저장
* \[ ] 프로그램 시작 시 기존 데이터 불러오기

저장 방식은 초기에는 JSON 파일을 사용하고, 필요하면 이후 SQLite로 변경할 예정

\## 7단계 - 미완료 학습량 재분배

계획대로 학습하지 못했을 경우 잔여 학습량을 이후에 다시 나누는 기능

* \[ ] 완료하지 못한 학습 항목 확인
* \[ ] 남은 날짜 계산
* \[ ] 남은 학습량 재분배
* \[ ] 학습 계획 갱신
